# Kanya Sibinda | QA Automation Engineer

This repository contains the source for [Kanya Sibinda's QA automation portfolio](https://ksibinda-sqae.github.io/).

The site presents practical automation work across web and API testing, with a focus on maintainable frameworks, reliable execution, useful diagnostics, and CI/CD integration.

## Featured projects

### Selenium Java Automation Framework

Custom Selenium WebDriver automation for Demo Web Shop application built with Java and TestNG. The framework uses the Page Object Model, reusable application components, centralised browser actions, structured logging, Allure reporting, test data management, and GitHub Actions execution.

Repository: [selenium-java-automation-framework](https://github.com/ksibinda-sqae/selenium-java-automation-framework)

### Playwright API Automation Project

TypeScript and Playwright API automation for authentication workflows against DummyJSON. The project includes typed API clients, services, request and response models, fixtures, data factories, domain assertions, structured logging, and Allure reporting.

Repository: [playwright-api-automation-project](https://github.com/ksibinda-sqae/playwright-api-automation-project)

### Playwright UI Automation Project

Standalone TypeScript and Playwright UI automation for SauceDemo. The suite covers login, logout, product details, and cart journeys through reusable page objects, flows, fixtures, assertions, diagnostics, and CI reporting.

Repository: [playwright-ui-automation-project](https://github.com/ksibinda-sqae/playwright-ui-automation-project)

## Running locally

The portfolio is a static page and has no build step. Open `index.html` directly in a browser, or serve the repository with any static web server:

```bash
npx serve .
```

The automation projects are maintained in their own repositories. Follow their individual READMEs for installation, environment configuration, test commands, and reporting instructions.
